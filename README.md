# dzhanibekov
Spacecraft attitude determination, dynamics, and estimation — a validated Python library. Quaternion kinematics, rigid-body dynamics, TRIAD/QUEST, and a Kalman-filter family (KF/EKF/MEKF), built from first principles with analytical-solution validation.

Named after the Dzhanibekov effect — the intermediate-axis instability this library reproduces from first principles and uses to validate its rigid-body dynamics.
